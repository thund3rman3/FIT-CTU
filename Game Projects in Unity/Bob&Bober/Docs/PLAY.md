# Run game

1. Download and open /Build from [Itch.io page](https://thund3r3.itch.io/bob-bober)
2. You wouldn’t be able to get through it alone; you will need a friend. One of you clicks Host in the game and chooses a session name. The other clicks Join and selects the correct session.

### Saving
If the player clicks Load while they are not disconnected from any session yet, nothing happens. The conditions for loading the last played level are set after clicking Save in the PauseMenu.

# Controls

- W/A/D + Shift - Shoot soul to swap bodies
- WASD - Movement
- Space - Jump
- E - Interact with levers, bomb crates
- Q - Throw bomb
- ESC - Open Pause Menu
