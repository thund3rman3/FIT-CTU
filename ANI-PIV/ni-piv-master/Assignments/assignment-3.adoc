### Objective
Implementation and evaluation of classification models (CNNs), analysis of their decision-making process (XAI), and learning image similarity using Siamese networks on the cilia/inpainting dataset.

---

### Part 1: Classification (Original vs. Inpainted)


- **Dataset:** Prepare the dataset from xref:exercise-7.adoc[Exercise 7] containing two classes: *original* cilia and *inpainted* modifications.
- **Models:** Implement and train two variations:
  1. A **custom** CNN architecture designed by you.
  2. A **pretrained** model (Transfer Learning) using a backbone like ResNet (frozen or fine-tuned).
- **Evaluation:** Compare the performance (accuracy, loss curves) of the custom model versus the pretrained approach.

*Deliverables:* Source code for both models, training logs, and a comparative summary in the report.

---

### Part 2: Model Interpretability


- Use the trained classification model from Part 1.
- Apply attribution methods (e.g., **Saliency**, **Integrated Gradients**, or **Grad-CAM**) to analyze the decision process.
- Visualise the results to demonstrate what features the network focuses on when distinguishing between original and inpainted images.

*Deliverables:* Visualizations of attribution maps for selected samples and a brief discussion on the model's focus areas. 

---

### Part 3: Siamese Networks


- **Task:** Build a Siamese network to determine image similarity (detect if two samples belong to the same class).
- **Implementation:**

  - Create positive (same class) and negative (different class) image pairs.
  - Implement a contrastive loss function.

- Evaluate the performance of the trained model

*Deliverables:* Siamese network implementation, training curves (loss), and evluation (+optionally: embedding space visualization)
